# Problem
Computational Complexity – P vs NP “Circuit‑size lower bound”

## Statement
Show that there exists an explicit Boolean function \(f : \{0,1\}^n \to \{0,1\}\) such that any Boolean circuit computing \(f\) requires size greater than \(2^{\Omega(n)}\). This lower bound would separate \(\mathsf{P}\) from \(\mathsf{NP}\).

## Remarks
- Known results: only super‑linear lower bounds for explicit functions (e.g., Hastad’s \(n^{1+\epsilon}\)).
- Proving exponential lower bound would resolve the P vs NP question.
- Placeholder for future formalization in Lean.

## 7. Apa which diperlukan for verifikasi which sah

Sebelum ada kode baru, perlu **pra-registrasi baru** which minimal memuat:

1. **Formula standar** tanpa faktor `2^(Ï‰(N)-1)`, with definisi `Î©`
   which eksplisit (periode real, jumlah komponen, normalisasi LMFDB).
2. **Conductor via Tate's algorithm**, bukan `|Î”|`.
3. **Torsion via division polynomials** or metode eksak lain, bukan tabel.
4. **Tamagawa via Tate's algorithm** in setiap prime buruk.
5. **Sha** for rank 0: minimal perhitungan 2-Selmer and bukti bahwa
   elemen Sha which terdeteksi trivial; jangan mengasumsikan `Sha=1`.
6. **Simbol modular eksak** (Manin symbols) with aritmetika
   `Fraction`/integer, termasuk penanganan Manin constant bila memakai
   kurva optimal `X_0(N)`.
7. **Guard which menguji klaim**, bukan mengunci tabel: mutasi nilai tabel
   harus menggagalkan guard; result harus dibandingkan with referensi
   eksternal which eksplisit.
8. **Receipt which memisahkan input, result, and referensi**, serta no
   memakai runtime/timestamp which no deterministik.

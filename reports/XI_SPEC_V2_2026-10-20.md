# Koreksi spec Xi V2: kontradiksi endpoint dihapus (2026-10-20)

**Status:** spec V2 baru, terpisah dari berkas beku; belum menggantikan
entri registry mana pun. Status push/CI dicatat di
`reports/HANDOFF.md` §2.0ai setelah commit.
**Berkas baru:** `lean/spec_v2/XiAnalyticSpecV2.lean`,
`msaf/tests/test_xi_spec_v2.py`, `lean/spec/README.md` (penunjuk).
**Yang tidak diubah:** `lean/spec/XiAnalyticSpec.lean` tetap
byte-identik dengan sertifikat `A-2026-0015`.

## 1. Cacat yang ditemukan

`lean/spec/XiAnalyticSpec.lean` (kondisional, 9 aksioma) **tidak
konsisten**. Probe di luar repo membuktikan `False` dari tiga fakta yang
tersedia di file itu:

1. `xiReal_sub_one 0 : xiReal 1 = xiReal 0`;
2. `xiReal 1 = 0` (faktor `(x - 1)` pada definisi produk, dievaluasi di
   `x = 1`);
3. `xiReal 0 = 1 / 2` (dari `zetaReal_zero` dan `gammaReal_one`).

Dua fakta terakhir memberi `0 = 1/2`. Selain itu, aksioma
`zetaReal_neg : ∀ x, x < 0 → zetaReal x < 0` salah untuk zeta yang
dimaksud: `riemannZeta (-2) = 0`, sedangkan `xiReal(-2) = xiReal 3 > 0`
dari persamaan fungsional/zeta di `-3`; aksioma itu juga tidak dipakai
oleh `#print axioms` teorema lama.

Karena berkas lama dipin `A-2026-0015` dan laporan/log beku tidak boleh
ditulis ulang, koreksi dibuat sebagai **berkas baru** yang menggantikan
pemakaian lama untuk pekerjaan berikutnya.

## 2. Perubahan V2

1. `xiReal` diberi guard pada titik removable `x = 1`:
   `if x = 1 then 1/2 else ...`; jadi `xiReal 1 = 1/2`, bukan `0`.
2. `xiReal_sub_one` dibatasi ke domain yang benar-benar dipakai langkah
   refleksi: `∀ x, x < 0 → xiReal (1 - x) = xiReal x` (untuk `x < 0`
   berlaku `1 - x > 1`).
3. Aksioma palsu dan tak terpakai `zetaReal_neg` tidak dibawa.

Jumlah aksioma V2: **8** (2 simbol opak `zetaReal`/`gammaReal` + 6
obligasi: `zetaReal_mid`, `zetaReal_gt_one`, `gammaReal_pos`,
`zetaReal_zero`, `gammaReal_one`, `xiReal_sub_one`). Teorema master
`xi_pos_on_reals` tetap membuktikan `0 < xiReal x` untuk semua `x : ℝ`
dalam model abstrak ini.

## 4. Batas

- Ini **spec abstrak kondisional**, bukan bukti tentang fungsi xi yang
  sebenarnya. `zetaReal`/`gammaReal` tetap opak; tidak ada klaim bahwa
  nilai-nilainya sama dengan zeta/Gamma klasik.
- Bentuk produk V2 masih **tidak faithful** di bilangan bulat genap
  negatif (faktor Gamma klasik punya kutub di sana, sedangkan nilai xi
  sebenarnya positif). Klaim hanya berlaku di dalam model abstrak V2.
- Bukan bukti Riemann Hypothesis, bukan peer review, dan tidak mengubah
  trusted base Coq empat aksioma stdlib.
- Berkas lama `lean/spec/XiAnalyticSpec.lean` tetap ada sebagai sejarah
  dan ditandai tidak sound oleh `lean/spec/README.md`; entri
  `A-2026-0015` tidak diubah.

## 5. Langkah berikutnya (belum dieksekusi)

`riemannZeta_zero`, `riemannZeta_pos_of_one_lt`,

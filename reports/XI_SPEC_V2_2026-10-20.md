## 1. Cacat which ditemukan

`lean/spec/XiAnalyticSpec.lean` (kondisional, 9 aksioma) **no
konsisten**. Probe in luar repo membuktikan `False` dari tiga fakta which
tersedia in file itu:

1. `xiReal_sub_one 0 : xiReal 1 = xiReal 0`;
2. `xiReal 1 = 0` (faktor `(x - 1)` on definisi produk, dievaluasi in
   `x = 1`);
3. `xiReal 0 = 1 / 2` (dari `zetaReal_zero` and `gammaReal_one`).

Dua fakta terakhir memberi `0 = 1/2`. Selain itu, aksioma
`zetaReal_neg : âˆ€ x, x < 0 â†’ zetaReal x < 0` salah for zeta which
dimaksud: `riemannZeta (-2) = 0`, sedangkan `xiReal(-2) = xiReal 3 > 0`
dari persamaan fungsional/zeta in `-3`; aksioma itu juga no dipakai
oleh `#print axioms` teorema lama.

Karena file lama dipin `A-2026-0015` and report/log beku no boleh
ditulis ulang, koreksi created sebagai **file baru** which menggantikan
pemakaian lama for pekerjaan berikutnya.

## 4. Batas

- Ini **spec abstrak kondisional**, bukan bukti tentang fungsi xi which
  sebenarnya. `zetaReal`/`gammaReal` tetap opak; no ada klaim bahwa
  nilai-nilainya sama with zeta/Gamma klasik.
- Bentuk produk V2 masih **no faithful** in bilangan bulat genap
  negatif (faktor Gamma klasik punya kutub in sana, sedangkan nilai xi
  sebenarnya positif). Klaim hanya berlaku in dalam model abstrak V2.
- Bukan bukti Riemann Hypothesis, bukan peer review, and no mengubah
  trusted base Coq empat aksioma stdlib.
- Berkas lama `lean/spec/XiAnalyticSpec.lean` tetap ada sebagai sejarah
  and marked no sound oleh `lean/spec/README.md`; entri
  `A-2026-0015` no diubah.

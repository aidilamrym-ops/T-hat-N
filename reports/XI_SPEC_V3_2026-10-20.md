## 1. Perubahan dari V2

V2 masih memakai simbol opak `zetaReal`/`gammaReal` dan delapan aksioma
deklaratif; bentuk produknya juga tidak faithful di bilangan bulat genap
negatif karena kutub Gamma klasik. V3 mengganti seluruh abstraksi itu
dengan fungsi Mathlib yang sebenarnya:

```text
xiReal x = 1/2                                  jika x = 0 atau x = 1
         = 1/2 * x * (x - 1) * Re Λ(x)          otherwise
```

dengan `Λ = completedRiemannZeta` dari Mathlib v4.33.1. Titik removable
`0` dan `1` dijaga ke `1/2`. Definisi memakai bagian real karena kodomain
di sini adalah `ℝ`.

## 2. Yang dibuktikan

Berkas V3 mendeklarasikan **nol** aksioma proyek. Semua deklarasi berikut
dikompilasi oleh Lean:

1. `gammaR_pos_of_pos`: `Gammaℝ (x : ℂ)` positif untuk real `x > 0`,
   memakai `Complex.ofReal_cpow`, `Complex.Gamma_ofReal`, dan
   `Real.Gamma_pos_of_pos`.
2. `completedZeta_pos_of_one_lt`: `0 < completedRiemannZeta (x : ℂ)`
   untuk real `x > 1`, memakai `riemannZeta_def_of_ne_zero`,
   `riemannZeta_pos_of_one_lt`, dan positivity `Gammaℝ`.
3. `xiReal_one_sub`: `xiReal (1 - x) = xiReal x` untuk **semua** real
   `x`, memakai `completedRiemannZeta_one_sub`; bukan aksioma.
4. `xi_pos_gt_one`: positivity di `x > 1`.
5. `xi_pos_below_one`: positivity di `0 < x < 1` dengan hipotesis
   eksplisit `hmid`.
6. `xi_pos_on_reals (hmid) (x) : 0 < xiReal x` untuk semua real `x`.
   Cabang `x < 0` dipantulkan ke `1 - x > 1`; titik `0` dan `1` dijaga.

## 4. Batas yang tetap berlaku

- **`hmid` belum dibuktikan.** Hipotesis
  `∀ x, 0 < x → x < 1 → (completedRiemannZeta (x : ℂ)).re < 0`
  adalah fakta benar tentang completed zeta, tetapi belum tersedia di
  Mathlib v4.33.1. V3 memindahkannya dari aksioma tersembunyi/opak
  menjadi parameter eksplisit; ia belum menjadi teorema tanpa syarat.
- **Realness `Λ` tidak diformalkan terpisah.** `xiReal` didefinisikan
  sebagai bagian real dari ekspresi standar. Untuk `x` real, ekspresi
  standar itu real secara matematis, tetapi V3 tidak membuktikan lemma
  realness `completedRiemannZeta` di sumbu real. Karena itu V3 tidak
  mengklaim lebih dari bagian real yang didefinisikan.
- **Bukan bukti RH**, bukan peer review, bukan klaim P≠NP/fisika.
- **Tidak mengubah trusted base Coq** empat aksioma stdlib; tidak
  menyentuh Paket 8/9.
- **V1/V2 tidak diubah.** `lean/spec/XiAnalyticSpec.lean` tetap
  byte-identik dengan `A-2026-0015`; V2 tetap byte-identik dengan
  `A-2026-0017`. V3 adalah berkas baru, bukan penulisan ulang laporan
  atau log beku.
- **`ci.yml` tidak diubah.** Untuk menjaga sertifikat `A-2026-0016`,
  V3 mendapat workflow terpisah `spec-v3.yml` dengan path filter
  `lean/spec_v3/**`, `msaf/tests/test_xi_spec_v3.py`, dan workflow itu
  sendiri.

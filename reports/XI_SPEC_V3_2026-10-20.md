## 4. Batas which tetap berlaku

- **`hmid` belum dibuktikan.** Hipotesis
  `âˆ€ x, 0 < x â†’ x < 1 â†’ (completedRiemannZeta (x : â„‚)).re < 0`
  adalah fakta benar tentang completed zeta, tetapi belum tersedia in
  Mathlib v4.33.1. V3 memindahkannya dari aksioma tersembunyi/opak
  menjadi parameter eksplisit; ia belum menjadi teorema tanpa syarat.

  sebagai section real dari ekspresi standar. Untuk `x` real, ekspresi
  standar itu real secara matematis, tetapi V3 no membuktikan lemma
  realness `completedRiemannZeta` in sumbu real. Karena itu V3 no
  mengklaim lebih dari section real which didefinisikan.

  menyentuh Paket 8/9.

  byte-identik with `A-2026-0015`; V2 tetap byte-identik with

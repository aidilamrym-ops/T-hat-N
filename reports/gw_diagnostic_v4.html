Panel 4 — definitions, derivations and pre-registered verdict rules

The exact definitions behind panels 1–3, as implemented by the canonical instrument and pre-registered before execution. Nothing on this dashboard changes these rules.

4.1 · S1 — mean adjacent gap ratio (unfolding-free)

For levels x1 < ⋯ < xD:

si = xi+1 − xi,    ri = min(si, si+1)max(si, si+1),    r̄ = meani ri(1)

Charts:

T: xi = ln λi (primary)  ·  L: xi = λi (secondary)(2)

The statistic is applied to both charts unconditionally; the flattering chart is never chosen afterwards. Chart L is non-uniform across tens–hundreds of orders in λ; the preregistration explains its role as the secondary reading.

4.2 · S2 — pair correlation versus the Montgomery kernel

R2(u) = 1 − (sin(πu)πu)2,    R2(0) = 0(3)

Target kernel (u = unfolded separation); R2(0) = 0 (level repulsion).

xk = Σm Φ( yk − ymσu hm )(4)

Unfolding: Gaussian-kernel smoothing of the counting function with adaptive bandwidth σu times the local mean spacing hm (from ±10 neighbours), then rescaled so the mean gap is exactly 1.

R2est(u) = 1D Σi≠j Gaussσe(u − (xi − xj))(5)

Estimator, compared against the target pushed through the estimator’s own smoothing (the apples-to-apples fix; no threshold was moved). Grid: σu ∈ {0.3, 0.5, 1.0} × {T, L}; σe = 0.5 fixed; u ∈ [0, 10) in 20 bins of width 0.5; bin weight = 1 / (matched-N GUE per-bin variance); bins with expected pair count below 5 are dropped and reported.

χ²obs = Σbins E ≥ 5 (cb − Tσe(ub))²VarGUE(b)    pGUE = P[χ²GUE ≥ χ²obs]    pPois = P[χ²Pois ≤ χ²obs](6)

Statistic and p-values. Poisson is tested on the lower tail (pre-registration #1001631, registered before any real spectrum was read; the S1/S2 rules are pre-registration #1001630).

4.3 · Verdict rules (pre-registered)

S1:

  • inside the Poisson reference only → CONSISTENT WITH POISSON
  • inside the RMT reference only → CONSISTENT WITH RMT
  • inside both → NO DISCRIMINATION
  • inside neither → INCONSISTENT WITH ALL THREE REFERENCES
  • the two charts disagree → CHART-DEPENDENT, hence INCONCLUSIVE

S2:

  • pGUE ≥ 0.05 and pPois < 0.05 → CONSISTENT WITH MONTGOMERY/GUE, distinguishable from Poisson
  • both ≥ 0.05 → NO DISCRIMINATION
  • pGUE < 0.05 → INCONSISTENT WITH MONTGOMERY AT THIS RESOLUTION
  • the verdict must hold on all 6 grid points, otherwise UNSTABLE, hence INCONCLUSIVE — the instability is reported and the favourable cell is never picked

References are matched-N simulations (GUE / GOE / Poisson, 2000 samples each, seed 20260927), never memorised constants. The same rules and the same seed are used in every run behind this dashboard.

4.4 · The lambda_min decay model, tested and refuted

λmin(n) ≈ A e−B n   (constant-B exponential form)(7)

constant-B exponential form fitted through the first two c = 13 points; refuted by points 3–4 — measured ln-slopes −1.72 → −1.05 → −0.34. The c = 13 plateau is UNCONFIRMED (dim 257/321 not yet measured).
